# BookStorage

A game about managing money.

## Goal of the game

- Have the most actions done without going out of money with which you started

## Requirements

- Java JDK Azul Zulu 24.0.2 (Tested on this version)
- JavaFX (Already installed through Maven)
- IDE with Maven support (IntelliJ)
